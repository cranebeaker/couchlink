Couchlink SDK

Your mod asks Couchlink which seat it is, which pad to read and where to draw. Cleanest result.

Recipe

No code in the game. A couchlink.json tells Couchlink how to run several copies side by side.

Try it

No recipe yet. Couchlink guesses with safe defaults and you report how it went.

Three steps
Step 1

Describe the game

Drop a couchlink.json next to your mod. Couchlink reads it when the game is found.

{
  "game": "Fallout: New Vegas",
  "steamAppId": 22380,
  "players": [2, 4],
  "mode": "instances",
  "exe": "FalloutNV.exe",
  "join": { "loopback": 27960 },
  "sdk": "couchlink_seat.dll"
}
Step 2

Ask for your seat

Optional. Link the tiny SDK and your mod knows its player, pad and screen rectangle.

// C, C++, C#, Lua bindings
CouchlinkSeat s;
if (couchlink_get_seat(&s)) {
  join("127.0.0.1", s.port);
  use_pad(s.pad);
  name_player(s.name);
}
Step 3

List it

Run /listing in the Co-op Anything Discord or edit your page on the site. Tick "Works with Couchlink" and it shows up here for everyone.

# or from your agent
coop_mcp validate couchlink.json
